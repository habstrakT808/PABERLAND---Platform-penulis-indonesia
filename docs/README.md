# Dokumentasi Project PaberLand

Struktur dokumentasi untuk project Literasi Nusantara (PaberLand).

## 📁 Struktur Folder

```
docs/
├── diagrams/          # Semua diagram (ERD, Sequence, dll)
│   ├── erd/          # Entity Relationship Diagram
│   └── sequence/     # Sequence Diagram
└── skripsi/          # File-file skripsi
```

## 📊 Diagrams

### ERD (Entity Relationship Diagram)
Folder: `diagrams/erd/`

- **ERD_PaberLand_Chen.puml** - ERD dalam format PlantUML (Chen Notation)
- **ERD_PaberLand_Chen_Mermaid.md** - ERD dalam format Mermaid (Chen Notation)
- **ERD_PABERLAND_LENGKAP.md** - ERD lengkap dengan penjelasan detail
- **ERD_PaberLand.md** - ERD dalam format dbdiagram.io

### Sequence Diagram
Folder: `diagrams/sequence/`

- **Sequence_Diagram_Daftar_Akun_Baru.puml** - Sequence diagram untuk use case registrasi
- **Sequence_Diagram_Login_Pengguna.puml** - Sequence diagram untuk use case login

## 📝 Skripsi

Folder: `skripsi/`

- **SKRIPSI.md** - File skripsi utama
- **Template Skripsi.md** - Template untuk penulisan skripsi

## 🔧 Cara Menggunakan

### ERD
- PlantUML: Buka file `.puml` di PlantUML viewer atau VS Code dengan extension PlantUML
- Mermaid: Buka file `.md` di Mermaid Live Editor atau VS Code dengan extension Mermaid

### Sequence Diagram
- PlantUML: Buka file `.puml` di PlantUML viewer atau VS Code dengan extension PlantUML

## 📌 Catatan

- Semua diagram menggunakan format PlantUML untuk konsistensi
- ERD menggunakan Chen Notation
- Sequence diagram mengikuti template yang sama dengan use case specification
