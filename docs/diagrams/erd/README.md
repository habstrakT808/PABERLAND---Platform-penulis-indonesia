# ERD (Entity Relationship Diagram)

Folder ini berisi semua ERD untuk project PaberLand.

## 📄 File

- **ERD_PaberLand_Chen.puml** - ERD dalam format PlantUML (Chen Notation)
- **ERD_PaberLand_Chen_Mermaid.md** - ERD dalam format Mermaid (Chen Notation)
- **ERD_PABERLAND_LENGKAP.md** - ERD lengkap dengan penjelasan detail (100% valid dari database)
- **ERD_PaberLand.md** - ERD dalam format dbdiagram.io

## 📊 Notasi

Semua ERD menggunakan **Chen Notation** dengan karakteristik:
- Entity: Kotak (hanya nama entitas)
- Atribut: Oval terpisah
- Relationship: Diamond (layang-layang)
- Cardinality: Crow's Foot notation

## 🔍 ERD Lengkap

File **ERD_PABERLAND_LENGKAP.md** adalah ERD yang paling lengkap dan 100% valid berdasarkan database migration. File ini mencakup:
- Semua 12 entitas
- Semua atribut dengan tipe data
- Semua relasi dengan cardinality
- Penjelasan detail setiap entitas dan relasi
