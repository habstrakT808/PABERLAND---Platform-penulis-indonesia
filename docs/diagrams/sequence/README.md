## 📊 Format

Semua sequence diagram menggunakan format **PlantUML** dengan:
- Actor: Pengguna
- Boundary: UI Components
- Control: Controller
- Entity: Service Providers
- Database: Database

## 🔧 Cara Menggunakan

1. Buka file `.puml` di PlantUML viewer
2. Atau gunakan VS Code dengan extension PlantUML
3. Atau gunakan online editor: http://www.plantuml.com/plantuml/uml/

## 📌 Catatan

- Sequence diagram dibuat sesuai dengan use case specification
- Method/fungsi yang digunakan sesuai dengan implementasi di codebase
- Diagram dibuat ringkas namun tetap mencakup semua alur penting
