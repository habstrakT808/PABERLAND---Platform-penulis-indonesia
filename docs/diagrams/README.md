# Diagrams

Folder ini berisi semua diagram untuk project PaberLand.

## 📁 Subfolder

- **erd/** - Entity Relationship Diagram (ERD)
- **sequence/** - Sequence Diagram untuk berbagai use case

## 📊 Format

- **PlantUML (.puml)** - Format utama untuk semua diagram
- **Mermaid (.md)** - Format alternatif untuk ERD

## 🔧 Tools

- PlantUML: http://www.plantuml.com/plantuml/uml/
- Mermaid Live Editor: https://mermaid.live/
