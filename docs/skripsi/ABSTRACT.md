# ABSTRACT

Hafiyan Al Muqaffi Umary, DEVELOPMENT OF WEB-BASED PABERLAND CHILDREN'S LITERACY WRITERS COMMUNITY PLATFORM USING NEXT.JS FRAMEWORK AND POSTGRESQL FOR PUBLICATION AND MANAGEMENT OF CHILDREN'S LITERACY WORKS
Supervisors: Bayu Priyambadha, S.Kom., M.Kom., Ph.D. and Dr. Achmad Arwan, S.Kom., M.Kom.

The Forum Penulis Bacaan Anak (PaberLand) is a community with more than 27,000 members that still relies on conventional social media platforms. The limitations of these platforms in supporting professional writers' needs became the background of this research. This research aims to develop a specialized web platform for the PaberLand children's literacy writers community with modern architecture.

The research uses Research and Development methodology with a prototyping development model through four stages: requirements analysis, system design, implementation, and testing. Requirements analysis resulted in 10 functional requirements and 7 non-functional requirements. System design produced class diagrams, sequence diagrams, and Physical Database Design with 8 main tables. Implementation uses Next.js 15 technology, PostgreSQL with Supabase, and TinyMCE for WYSIWYG editor.

Implementation results show that all 10 functional requirements were successfully realized, including authentication system, WYSIWYG editor with auto-save, article management, nested comment system, like system, content discovery, profile and portfolio management, admin panel, real-time notification system, and content reporting system. Black Box Testing resulted in 100% valid on 50 test cases. White Box Testing resulted in 40 valid test cases out of 43 test cases on 10 critical functions.

Based on the research results, it can be concluded that the PaberLand platform has been successfully developed and meets all the specified requirements. The system can be used by the Indonesian children's literacy writers community to share and develop works in a more organized and productive manner.

**Keywords:** community platform, children's literacy, Next.js, PostgreSQL, software engineering, system testing
